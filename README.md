A radar for protocols that have not issued a token yet: it scores every pre-token protocol on DefiLlama's index by an implied value built from its TVL, its business, its seven-day growth and how long it has run without a token, then hands the reader a farm plan with real costs and holding periods.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
